# Data attribution

This project uses third-party open data. Attribution required:

- Routing: **OpenRouteService** (© openrouteservice.org, data © OpenStreetMap contributors) — CC BY 4.0
- POIs: **OpenTripMap** / **OpenStreetMap Overpass** — ODbL
- Weather: **Open-Meteo** — CC BY 4.0
- Fuel prices: **European Commission Weekly Oil Bulletin** (via fuel-prices.eu) — CC BY 4.0
- Accommodation: **Inside Airbnb** — CC BY 4.0
- Cost of living: **WhereNext** (getwherenext.com; World Bank/OECD/Eurostat) — CC BY 4.0
- Flight prices: **Travelpayouts / Aviasales Data API** (indicative, cached)
